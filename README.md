# Naydi — платформа «найди рядом» (MVP, Бишкек)

Full-stack MVP по ТЗ: поиск товаров, услуг и проверенных специалистов рядом,
сравнение, доверие (верификация, отзывы, рейтинги), чат, заказы, кабинеты
бизнеса/специалиста, AI-поиск и админ-панель.

## Как запустить

```bash
npm install          # уже выполнено
npx prisma db push   # уже выполнено (SQLite prisma/dev.db)
npm run db:seed      # уже выполнено (demo-данные Бишкека)
npm run dev          # → http://localhost:3000
```

> На этой машине Node установлен в `C:\Users\user\nodejs` — если `npm` не находится
> в новом терминале, добавьте эту папку в PATH (установка делалась через winget).

## Что внутри (по ТЗ)

- **Роли**: CUSTOMER / BUSINESS / SPECIALIST / ADMIN, сессии на JWT (jose), bcrypt, rate limiting, middleware-защита маршрутов, серверная проверка прав.
- **Поиск**: единый сервис `services/search.ts` — товары/услуги/специалисты/бизнесы, фильтры (цена, расстояние, рейтинг, наличие, б/у, опыт, выезд, проверенные, открыто сейчас), 8 сортировок, ранжирование по формуле раздела 41 (релевантность + расстояние + рейтинг + отзывы + доступность + верификация; продвижение — с пометкой «Реклама»).
- **Карта**: `/map` на Leaflet + OpenStreetMap (без API-ключа), маркеры с мини-карточками, зелёные пины = проверенные.
- **AI-поиск**: `/assistant` — разбор запроса на естественном языке (цена, категория, время, «рядом»), вызовы внутреннего поиска (`searchOffers`), лучшие подборки на реальных данных. Без LLM-ключа работает встроенный fallback-парсер; с ключом (`OPENAI_API_KEY`, `OPENAI_BASE_URL`, `AI_MODEL` в `.env`) — tool calling любой OpenAI-совместимой модели.
- **Верификация**: заявки с документами, статусы PENDING/VERIFIED/REJECTED/SUSPENDED, значок «✓ Проверенный» с юридическим пояснением.
- **Отзывы**: 1–5 звёзд + критерии (качество, соответствие, скорость, общение, цена), денормализованные рейтинги, модерация.
- **Чат**: диалоги клиент↔бизнес/специалист, текст + фото, статусы прочтения, опрос каждые 5 с.
- **Заказы**: статусы NEW → ACCEPTED → IN_PROGRESS → COMPLETED / CANCELLED, валидация переходов, «Мои заказы» и «Заказы клиентов».
- **Кабинеты**: бизнес (статистика, товары, услуги, заказы, верификация), специалист, профиль пользователя (геолокация, избранный, история поиска).
- **Жалобы**: 7 причин, модерация в админке.
- **i18n**: русский + английский (переключатель в шапке), все тексты через словари.
- **Mobile-first**: нижняя навигация (у бизнеса — свой набор), адаптив до 360 px, карточки/кнопки под палец.
- **SEO**: метаданные, названия страниц, OG-теги, публичные страницы индексируются.
- **Архитектура**: `app/` (страницы+API), `components/`, `services/`, `lib/` (auth, geo, ranking, i18n, ai, storage, validation, rate-limit), `prisma/` (схема, seed), `types/`. 27 таблиц, ready-for-PostgreSQL (сменить provider в `prisma/schema.prisma`).
